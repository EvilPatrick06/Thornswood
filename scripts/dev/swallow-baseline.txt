# Silent catches in the launcher, per file. Read by scripts\dev\Check-Swallow.ps1,
# which fails when any file in launcher\app has more than its line here allows.
# A file that is not listed is allowed none.
#
# THE RULE. A catch counts when the body between its braces is empty or holds
# nothing but whitespace, whether the braces sit on one line or on lines of
# their own. A catch naming an exception, catch (IOException), counts the same
# as a bare one. A body holding only a comment does NOT count: a comment inside
# the braces is somebody saying on purpose why nothing is done, which is the
# deliberate swallow entry 239 says to leave alone. A comment beside the
# braces, after the closing one, is outside the body, so that catch still
# counts. On 24 Sep that choice was worth one catch, where Chars.cs writes the
# character menu's script: 386 by this rule, 387 counting it.
#
# The numbers are catch clauses, not lines. The Select-String line in entry
# 239 counts lines, so it shows Shell.cs at 78 where this shows 80: two of its
# lines hold two empty catches each. .\scripts\dev\Check-Swallow.ps1 -List prints
# the numbers below in this same format.
#
# The count reads the text, so a comment or a string that spells out an empty
# catch is counted as one. Nothing in launcher\app does that today.
#
# A number here only goes down. When a file's count drops, lower its line in
# the same pull request. To make a catch stop counting, log it with
# Swallow.Note (launcher\app\Swallow.cs). Raising a number is a decision for
# Patrick, not a fix.
#
# Measured 24 Sep: 386 silent catches of 618 before this list existed. The
# places entry 239 named, Config.Save, Swap.Restore with the DropLink it
# starts with, Hold.Release and Keep.Unpark, log instead now, which is the ten
# fewer below: 376.
#
# Main brought five more before this list reached it, all with Steam's Updates
# setting: one in Shell.cs, one in ShellSteamUpdates.cs and three in
# SteamUpdates.cs. The first two log with Swallow.Note. The three in
# SteamUpdates.cs say why in a comment instead, because test-steam-updates.ps1
# compiles that class on its own and it cannot reach Swallow. So the numbers
# below held at 376 and none was raised.
#
# Main brought seven more on the second merge, the same afternoon: two in
# Shell.cs where the launcher clears the copy its self update kept, two in
# SelfSwap.cs and three in ShellUninstall.cs. The two in Shell.cs, and the
# scroll and status line in ShellUninstall.cs, log with Swallow.Note. The two
# in SelfSwap.cs say why in a comment, because test-self-update.ps1 compiles
# that class on its own. The third in ShellUninstall.cs, the fault handler's
# write to the log, says why in a comment too, because it is the log that
# failed. Still 376, and none was raised.
