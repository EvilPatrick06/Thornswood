# Getting help

- **Joining, installing or playing.** Ask in the
  [Discord](https://thornswood.net/discord). [thornswood.net/join](https://thornswood.net/join)
  walks through joining, and [thornswood.net/help](https://thornswood.net/help)
  answers the common questions.
- **Something broken, or an idea.** Look at the
  [known issues](https://thornswood.net/known) first. Then report it on
  [thornswood.net/report](https://thornswood.net/report), which needs no
  account, or open an issue here with one of the
  [forms](https://github.com/EvilPatrick06/Thornswood/issues/new/choose).
- **The server is down.** Say so in the Discord.
- **Somebody behaving badly.** Report them on
  [thornswood.net/report](https://thornswood.net/report), signed in, never as
  an issue. [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) says what the rules are.
- **A security hole.** Never as an issue, and never in a Discord channel.
  [SECURITY.md](SECURITY.md) says where to send it.
- **Sending a change.** [CONTRIBUTING.md](CONTRIBUTING.md).
