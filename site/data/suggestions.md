# Suggestions

Requested mods and features. Nothing here is committed.

Paste the Nexus link when suggesting a mod. Whether it can work here depends on how it is built, not what it does.

## Whether a mod will work here

| Category | Works | Examples |
|---|---|---|
| Meshes and textures | Yes | Replacers, parallax, LOD |
| Weather, lighting, water | Yes | Cathedral Weathers, Water for ENB |
| Sound and music | Yes | Immersive Sounds |
| Animation replacers | Yes | Existing event names only |
| Interface and HUD | Yes | SkyUI, SkyHUD |
| New worldspaces and buildings | Yes | JK's, The Great Cities |
| New armour, weapons, clothing | Yes | As records, not script distributed |
| New spells as records | Yes | Odin |
| Moves your character | No | Teleport spells, fast travel overhauls |
| Changes health, stats or damage | No | Survival mods, combat overhauls |
| Adds or removes items by script | No | Loot mods, crafting that spawns items |
| Alters containers | No | Container overhauls, auto sorters |
| Runs its own quests | No | Quest mods, radiant quest systems |
| Keeps its own progress | No | Anything with a settings menu or counters |
