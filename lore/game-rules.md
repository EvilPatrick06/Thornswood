# Rules in the World

The rules for playing here are on the site, at
[thornswood.net/rules](https://thornswood.net/rules), under "In the World".

That page is the only copy. Its file is `site\data\site\rules.md`, and
`#game-rules` in the Discord is read out of the same file, so the two cannot
disagree. Change the rules there, not here.

This file used to carry a copy of its own, numbered differently, and it said a
fight between two people was agreed first while the site said fights start
freely. Patrick decided on 28 September that fights start freely, and this
copy went (issue #430).
