Skyrim co-op. One install, and it does not touch the Skyrim you already have.
Keizaal Online, Daedric Online, your own mod setup, all of it keeps working.


DOWNLOAD
https://drive.google.com/drive/folders/1zESrSYy6s-kzUtCVF6g0RMrfCUvooTaT?usp=drive_link

There are TWO files and you need both, in the same folder:

  SkyrimTogether-Setup.exe   57 KB, this is the one you run
  SkyrimTogether-Setup.zip   10.7 GB, everything else

Google Drive will say it cannot scan the big one for viruses. Click "Download
anyway". Do NOT unzip it yourself, the exe does that.


WHAT YOU NEED
- Skyrim Special Edition on Steam, on this PC
- About 32 GB free on whichever drive you pick. It settles at about 18 GB.
  The setup window lists your drives with how much room each one has, so
  it does not have to be C:.
- Steam signed in and running


INSTALL
Put both files in the same folder and run SkyrimTogether-Setup.exe. It shows you
which zip it found before you press anything, so if it says the zip is missing,
the two are not together yet.

Windows will say "Windows protected your PC" because the file is not signed.
More info, then Run anyway. Every unsigned program does this.

Press Install and leave it alone. It unpacks, copies the plain Bethesda files
out of your Steam folder into the folder you picked, and sets that copy up with the
whole mod list already installed. You do not install any mods. No Nexus account,
no Vortex, no Nemesis.

It only ever reads your Steam copy, and only the files Bethesda shipped. Nothing
you have installed there comes along, and nothing there is renamed, patched or
deleted.


THE ONE STEP IT MAY ASK YOU FOR
Our server runs game build 1.6.1170. If your Skyrim is a different build, which
it will be if you have been playing Keizaal or Daedric, the installer stops and
shows you three download_depot commands, already on your clipboard. Paste them
into the Steam console ONE AT A TIME and wait for each to print Done. There is no
progress bar, so it looks stuck when it is not. Then press Enter back in the
installer window.

That is Steam handing you an older build of a game you already own. It downloads
into Steam's own folder and does not change your installed game.

It may also do this on its own if it finds that another multiplayer setup has
patched your Skyrim. Same three commands, same result.


FIRST TIME IN GAME
You get a "Thornswood" shortcut on your desktop. Open it.

If it offers you an update, take it BEFORE you press Play. The installer is a
snapshot and the launcher keeps itself current, so the first update is usually
the difference between having the server preset in step 3 and not having it.

1. New Game. There is no cart ride and no Helgen in this build.
2. Make your character and NAME IT AFTER YOURSELF. That name is what the rest
   of us see over your head, and changing it later means starting over.
3. You wake in a small room. Press ENTER, then choose the "Server" preset. That
   sets the world options so all five of us match.
4. Esc, Mod Configuration, Skyrim Unbound, and pick your own Starting Location.
   Where you start is yours alone. Pick anywhere, even the far side of Skyrim.
   We can teleport to each other from the party menu.
5. Begin Your Adventure.
6. Save once.

It connects to the server by itself a couple of seconds after your save loads.
No address to type, no password to ask anyone for. If it ever does not take,
press F2 and use Connect.


THINGS TO KNOW
- F2 opens the multiplayer menu: party, who is online, teleport, chat.
- Sleeping and waiting do nothing. Time is shared across the server.
- Menus do not pause the game. Do not sort your bags mid fight.
- You get hungry, thirsty and cold. Eat, drink, stay warm.
- Party up before starting a quest and let one person lead it.
- Do not run Steam's "Verify Integrity of Game Files" on Skyrim.
- Do not add mods with a plugin. The launcher checks your list before it lets
  you play, and the server turns away anyone whose list does not match.
  Textures, meshes and sounds are fine. There is a folder for them under Mods.

Updates come through the launcher. When the mod list changes you get only the
files that changed, not the whole thing again. Take them when it offers, because
a list that does not match cannot connect.

If something is wrong, the launcher's Play page shows five checks and any red
row is the actual problem. Screenshot it and send it over.
