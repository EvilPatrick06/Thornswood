# Check-Secrets.allow.txt
#
# Known non-secrets that a rule in tools\Check-Secrets.ps1 matches. One per
# line: a path, then the rule it is allowed for. The path is compared with
# -like, so * works, and it is the path as the scan reports it with forward
# slashes: repository relative for the tree, the entry name inside a zip
# (game/Data/...), the path under the folder for -Dir, the file name for
# -Binary.
#
# Every line says why the thing is safe. A real secret never goes here: one
# that is found is taken out and replaced, and then the scan passes on its own.

# The voice service's harness for token renewal. The name carries the word
# "token" because that is what it tests; it holds no token, it asks the
# service it starts in a temp folder for fresh ones.
voice/test-token-refresh.js  credential-file-name

# The harness for Deploy-Docs -Password. "password" is in its name because
# that is the switch it tests. Every value in it is made up in the open
# (not-a-real-secret, not-a-real-token, 111111111111111111) and it writes
# only to its own temp folder.
tests/test-docs-password.ps1  credential-file-name

# The harness for the session log upload. It feeds the launcher's Scrub a
# join token in the exact shape voice-server.js signs, because the point is to
# prove that shape is taken out of a log before it leaves. The comment above it
# says it is made up: the profile id, the expiry and the signature are all
# invented, and nothing ever issued it.
tests/test-log-upload.ps1  voice-join-token
